1. Pobierz repozytorium na komputer

Jeśli OpenCar3D jest już widoczne w Current Repository, wybierz je i przejdź do następnej sekcji. W innym przypadku:

  1. Otwórz GitHub Desktop

    Zaloguj się na konto z prawem zapisu do FractalBoy9X/OpenCar3D.

  2. Wybierz File → Clone Repository… → URL

    Wklej adres repozytorium:

    https://github.com/FractalBoy9X/OpenCar3D

  3. Wskaż Local Path i kliknij Clone

    To folder na Twoim dysku, w którym będzie lokalna kopia. Zapamiętaj tę lokalizację; kolejne zmiany robisz właśnie w tym folderze.

  4. Otwórz folder projektu

    Wybierz Repository → Show in Finder (Windows: Show in Explorer). Otwórz sedan-lab-anatomia.html w przeglądarce. Nie musisz instalować pakietów ani uruchamiać serwera.

Repozytorium już istnieje. Korzystaj z Clone Repository. Przycisk Publish repository służy do utworzenia nowego zdalnego repozytorium i nie jest potrzebny w tym przypadku.

2. Wrzucaj kolejne zmiany

  1. Wybierz OpenCar3D i pobierz aktualizacje

    Sprawdź Current Repository: OpenCar3D oraz Current Branch: main. Kliknij Fetch origin. Jeżeli pojawi się Pull origin, kliknij je przed rozpoczęciem edycji.

  2. Skopiuj lub zmień pliki w folderze repozytorium

    Jeżeli dostałeś ode mnie nową wersję, skopiuj ją do folderu OpenCar3D otwartego przez Show in Finder. Pliki leżące obok tego folderu nie zostaną wysłane. Zamieniaj tylko pliki należące do tej aktualizacji.

  3. Jeśli zmieniasz źródła — wygeneruj gotowy HTML

    W Terminalu otwartym w katalogu OpenCar3D wykonaj poniższe polecenia. Wymagają odpowiednio Pythona 3 i Node.js. Ten krok nie jest potrzebny, gdy tylko pobierasz i uruchamiasz gotowy projekt.

    python3 sedan-lab/build_offline.py
node sedan-lab/check-model.cjs

    Edytuj źródła w sedan-lab/dist/; skrypt złoży je do sedan-lab-anatomia.html. Do commitu dodaj źródła i wygenerowany HTML.

  4. Sprawdź działanie

    Otwórz lokalny HTML. Sprawdź widok auta, wybór części, mechanizm silnika i element, który zmieniałeś. Po podmianie otwartego pliku odśwież kartę przeglądarki.

  5. Przejrzyj zakładkę Changes

    GitHub Desktop pokaże zmienione i nowe pliki automatycznie. Klikaj je, aby zobaczyć różnice. Zaznacz tylko pliki projektu przeznaczone do publikacji. Duży HTML zawiera biblioteki i HDR, więc jego podgląd różnic może być obszerny.

  6. Wpisz opis i zrób commit

    W polu Summary wpisz np. Improve brake caliper geometry. Kliknij Commit to main (w niektórych wersjach aplikacji: Commit… oraz osobno zatwierdzenie). Commit zapisuje wersję lokalnie.

  7. Kliknij Push origin

    Dopiero Push origin wysyła commit na GitHuba. Jeśli aplikacja wymaga najpierw pobrania zmian, zrób Fetch/Pull i przejrzyj ewentualne konflikty. Nie używaj Force push do zwykłych aktualizacji.

  8. Sprawdź wynik na GitHubie

    Wybierz Repository → View on GitHub. Na stronie sprawdź ostatni commit i obecność aktualnych plików. Po zakończeniu GitHub Desktop powinien pokazać No local changes i brak commitów oczekujących na Push.

Commit ≠ Push. Commit zapisuje punkt historii na komputerze. Push publikuje tę historię w repozytorium na GitHubie.

5. Opcjonalnie: uruchamianie przez link

Wrzucenie HTML do repozytorium zapisuje plik. Strona github.com pokazuje jego kod; do uruchamiania aplikacji przez link możesz osobno włączyć GitHub Pages.

  1. Otwórz repozytorium → Settings → Pages

    Potrzebujesz uprawnień do ustawień repozytorium i dostępności Pages dla tego repozytorium/planu.

  2. Ustaw źródło publikacji

    W sekcji Build and deployment wybierz Deploy from a branch, gałąź main i folder /(root), potem Save.

  3. Poczekaj na zakończenie publikacji

    Sprawdź adres podany przez GitHuba w Pages oraz status wdrożenia w Actions. Dla domyślnego adresu tego repozytorium aplikacja będzie pod ścieżką:

    https://fractalboy9x.github.io/OpenCar3D/sedan-lab-anatomia.html

    To oczekiwany adres po włączeniu Pages, a nie potwierdzenie, że usługa jest już aktywna. Brak index.html w repozytorium nie przeszkadza w otwieraniu pełnej ścieżki powyżej.

Gdy coś nie działa

GitHub Desktop nie pokazuje moich plików

Sprawdź Current Repository i otwórz Show in Finder. Plik musi znajdować się wewnątrz lokalnego folderu OpenCar3D. Sprawdź też, czy jego ścieżka nie jest wykluczona przez .gitignore.

Widzę No local changes, ale na GitHubie nie ma aktualizacji

Sprawdź, czy u góry jest Push origin. Commit mógł zostać zapisany lokalnie i czekać na wysłanie. Upewnij się też, że oglądasz na stronie tę samą gałąź.

GitHub pokazuje kod HTML zamiast samochodu

To normalny podgląd pliku w repozytorium. Pobierz go i otwórz z dysku albo skorzystaj z GitHub Pages po jego osobnym skonfigurowaniu.

Pojawił się konflikt albo błąd uprawnień

Nie nadpisuj historii na siłę. Przy konflikcie przejrzyj wskazane pliki i wybierz właściwe zmiany przed kolejnym commitem. Przy błędzie uprawnień sprawdź konto zalogowane w GitHub Desktop i jego dostęp do FractalBoy9X/OpenCar3D.
